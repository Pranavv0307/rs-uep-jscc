# Insights

- Based on 3 channel seed(s); 5000 images per seed. All gains below are paired per seed against the baseline (same packet losses), so they carry no luck-of-the-draw advantage.
- Break-even: the best protected method overtakes `uniform` from about erasure_rate = 0.34.
- Low-loss penalty: even the best method is 1.26 dB below `uniform` at erasure_rate = 0.3 (two_tier_50_50@random). This is the block-length effect of a single large RS block, which tiered coding gives up.
- Peak gain: +1.69 dB at erasure_rate = 0.4 by three_tier_25_50_25@predicted (95% CI ±0.09, significant).
- Importance sources ranked by their best scheme's mean gain over erasure_rate >= 0.35: predicted +1.17 dB, oracle +0.72 dB, attention +0.55 dB, random +0.46 dB.
- Share of the oracle gain captured: predicted 164%, attention 77%, random 65%.
- Random-order control gains +0.46 dB versus oracle +0.72 dB, so the benefit comes from *which* channels are protected, not merely from tiering.
- Worst-case images at erasure_rate = 0.4: 5th-percentile PSNR 18.62 dB (three_tier_25_50_25@predicted) vs 17.25 dB (uniform).
- Worst-case images at erasure_rate = 0.5: 5th-percentile PSNR 16.46 dB (three_tier_25_25_50@predicted) vs 15.90 dB (uniform).
- Seed sensitivity: std across channel seeds stays below 0.3 dB everywhere.
- `uniform` shows its steepest fall (-3.89 dB) between erasure_rate = 0.3 and 0.35 -- its cliff.
